Le cloud computing est le déploiement à la demande de puissance de calcul, de stockage, de bases de données, d'application et d'autres ressources informatiques par internet. 
Il y a 200 services du cloud.
Coupé en plusieurs niveau de services
Les 3 grande entreprise à faire du cloud: 
	AWS : Amazon
	Azure : Microsoft
	Google 

IAAS = infrastructure as a service
PAAS = plateforme as a service
SAAS = software as a service

3 Moyen d'interagir avec aws:
	 management console
	 interface de ligne de commande
	 kit de développement logiciel

3 facterus fondamentaux de coûts avec aws : 
	Calcul
	stockage
	transfert de données
